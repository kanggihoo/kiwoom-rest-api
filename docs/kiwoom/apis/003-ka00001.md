# ka00001 계좌번호조회

- 분류: 국내주식 / 계좌
- 메뉴 위치: 국내주식 > 계좌 > 계좌번호조회(ka00001)
- Method: `POST`
- 운영 도메인: `https://api.kiwoom.com`
- 모의투자 도메인: `https://mockapi.kiwoom.com(KRX만 지원가능)`
- URL: `/api/dostk/acnt`
- Format: `JSON`
- Content-Type: `application/json;charset=UTF-8`
- PDF 페이지: 10~10

## 개요

현재 토큰의 계좌번호를 조회합니다.

## Request Fields

| 위치 | Element | 한글명 | Type | Required | Length | Description |
| --- | --- | --- | --- | --- | --- | --- |
| Header | api-id | TR명 | String | Y | 10 |  |
| Header | authorization | 접근토큰 | String | Y | 1000 | 토큰 지정시 토큰타입("Bearer") 붙혀서 호출<br>예) Bearer Egicyx... |
| Header | cont-yn | 연속조회여부 | String | N | 1 | 응답 Header의 연속조회여부값이 Y일 경우 다음데이터<br>요청시 응답 Header의 cont-yn값 세팅 |
| Header | next-key | 연속조회키 | String | N | 50 | 응답 Header의 연속조회여부값이 Y일 경우 다음데이터<br>요청시 응답 Header의 next-key값 세팅 |

## Response Fields

| 위치 | Element | 한글명 | Type | Required | Length | Description |
| --- | --- | --- | --- | --- | --- | --- |
| Header | api-id | TR명 | String | Y | 10 |  |
| Header | cont-yn | 연속조회여부 | String | N | 1 | 다음 데이터가 있을시 Y값 전달 |
| Header | next-key | 연속조회키 | String | N | 50 | 다음 데이터가 있을시 다음 키값 전달 |
| Body | acctNo | 계좌번호 | String | N | 20 | 10자리 숫자가 출력됩니다. 뒤에 2자리는 당사에서 계좌를<br>분류하기 위한 값입니다. |
