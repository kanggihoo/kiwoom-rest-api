# ka20003 전업종지수요청

- 분류: 국내주식 / 업종
- 메뉴 위치: 국내주식 > 업종 > 전업종지수요청(ka20003)
- Method: `POST`
- 운영 도메인: `https://api.kiwoom.com`
- 모의투자 도메인: `https://mockapi.kiwoom.com(KRX만 지원가능)`
- URL: `/api/dostk/sect`
- Format: `JSON`
- Content-Type: `application/json;charset=UTF-8`
- PDF 페이지: 259~260

## 개요

_문서에 별도 개요가 없습니다._
