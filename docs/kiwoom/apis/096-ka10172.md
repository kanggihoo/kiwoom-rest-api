# ka10172 조건검색 요청 일반

- 분류: 국내주식 / 조건검색
- 메뉴 위치: 국내주식 > 조건검색 > 조건검색 요청 일반(ka10172)
- Method: `POST`
- 운영 도메인: `wss://api.kiwoom.com:10000`
- 모의투자 도메인: `wss://mockapi.kiwoom.com:10000(KRX만 지원가능)`
- URL: `/api/dostk/websocket`
- Format: `JSON`
- Content-Type: `application/json;charset=UTF-8`
- PDF 페이지: 245~247

## 개요

조건검색은 영웅문4에서 만드실 수 있습니다.

| Header | cont-yn | 연속조회여부 | String | N | 1 | 응답 Header의 연속조회여부값이 Y일 경우 다음데이터<br>요청시 응답 Header의 cont-yn값 세팅 |
| Header | next-key | 연속조회키 | String | N | 50 | 응답 Header의 연속조회여부값이 Y일 경우 다음데이터<br>요청시 응답 Header의 next-key값 세팅 |
