# 0J 업종지수

- 분류: 국내주식 / 실시간시세
- 메뉴 위치: 국내주식 > 실시간시세 > 업종지수(0J)
- Method: `POST`
- 운영 도메인: `wss://api.kiwoom.com:10000`
- 모의투자 도메인: `wss://mockapi.kiwoom.com:10000(KRX만 지원가능)`
- URL: `/api/dostk/websocket`
- Format: `JSON`
- Content-Type: `application/json;charset=UTF-8`
- PDF 페이지: 505~507
