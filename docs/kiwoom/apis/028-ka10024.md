# ka10024 거래량갱신요청

- 분류: 국내주식 / 종목정보
- 메뉴 위치: 국내주식 > 종목정보 > 거래량갱신요청(ka10024)
- Method: `POST`
- 운영 도메인: `https://api.kiwoom.com`
- 모의투자 도메인: `https://mockapi.kiwoom.com(KRX만 지원가능)`
- URL: `/api/dostk/stkinfo`
- Format: `JSON`
- Content-Type: `application/json;charset=UTF-8`
- PDF 페이지: 80~81
