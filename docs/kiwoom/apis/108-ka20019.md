# ka20019 업종년봉조회요청

- 분류: 국내주식 / 차트
- 메뉴 위치: 국내주식 > 차트 > 업종년봉조회요청(ka20019)
- Method: `POST`
- 운영 도메인: `https://api.kiwoom.com`
- 모의투자 도메인: `https://mockapi.kiwoom.com(KRX만 지원가능)`
- URL: `/api/dostk/chart`
- Format: `JSON`
- Content-Type: `application/json;charset=UTF-8`
- PDF 페이지: 274~275

## 개요

_문서에 별도 개요가 없습니다._
