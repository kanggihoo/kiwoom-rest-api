# ka50080 금현물분봉차트조회요청

- 분류: 국내주식 / 차트
- 메뉴 위치: 국내주식 > 차트 > 금현물분봉차트조회요청(ka50080)
- Method: `POST`
- 운영 도메인: `https://api.kiwoom.com`
- 모의투자 도메인: `https://mockapi.kiwoom.com(KRX만 지원가능)`
- URL: `/api/dostk/chart`
- Format: `JSON`
- Content-Type: `application/json;charset=UTF-8`
- PDF 페이지: 325~326
