# 0I 국제금환산가격

- 분류: 국내주식 / 실시간시세
- 메뉴 위치: 국내주식 > 실시간시세 > 국제금환산가격(0I)
- Method: `POST`
- 운영 도메인: `wss://api.kiwoom.com:10000`
- 모의투자 도메인: `wss://mockapi.kiwoom.com:10000(KRX만 지원가능)`
- URL: `/api/dostk/websocket`
- Format: `JSON`
- Content-Type: `application/json;charset=UTF-8`
- PDF 페이지: 503~504

## 개요

_문서에 별도 개요가 없습니다._

| Header | next-key | 연속조회키 | String | N | 50 | 응답 Header의 연속조회여부값이 Y일 경우 다음데이터<br>요청시 응답 Header의 next-key값 세팅 |
