# Triage Labels

Issue triage labels are not configured for this repo because issue management is out of scope.

## Policy

Do not create or apply triage labels unless the user explicitly opts into issue tracking later.

The canonical triage roles below are intentionally unmapped:

| Role | Tracker label |
| --- | --- |
| `needs-triage` | Not used |
| `needs-info` | Not used |
| `ready-for-agent` | Not used |
| `ready-for-human` | Not used |
| `wontfix` | Not used |
